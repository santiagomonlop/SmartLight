This project is a simulation of an energy-conscious SmartLight that changes light output depending on the amount of sunlight, motion detection, and battery level. This project is built on wokwi.com. Wokwi.com is a browser-based electronics simulator where you can build and test digital circuits virtually. This project is done digitally to reduce costs and enhance exposition.
